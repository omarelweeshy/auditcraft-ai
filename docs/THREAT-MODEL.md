# Threat model

| Threat                                          | Current control                                                                                               | Remaining boundary                                                                     |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| SSRF, metadata access, redirects, DNS rebinding | Exact fixture allowlist; every browser route fulfilled locally or aborted; websockets closed; no local bypass | Public validator alone is insufficient for live scanning; live transport disabled      |
| Unauthenticated audit or report access          | Signed expiring HttpOnly SameSite cookie; every API/artifact requires authentication                          | Single administrator, no multi-user authorization or SSO                               |
| CSRF                                            | Exact configured Origin plus session-derived token on writes; Origin check on login                           | Deploy behind TLS and configure the canonical APP_URL                                  |
| Credential guessing                             | Global persisted failure count and 5-minute window                                                            | Local demo limiter; distributed rate limiting and stronger identity needed for hosting |
| Prompt injection / fabricated model findings    | No external page-to-LLM path; strict known templates and evidence IDs                                         | Free-form external providers not implemented                                           |
| Stored XSS in reports                           | Escaped data, no user HTML, strict report CSP, PDF network denied                                             | Application CSP and broader browser hardening remain future work                       |
| Arbitrary file disclosure                       | UUID-and-capture-name allowlist, resolved path containment, session checks                                    | Host filesystem access is outside the application security boundary                    |
| Unsupported commercial claims                   | Exact generated templates, human gate, numeric/guarantee checks                                               | Human edits are not semantically proven truthful; reviewer accountable                 |
| Lost jobs / worker crash                        | SQL outbox, heartbeat, BullMQ lease/stall handling, bounded attempts                                          | Redis persistence and database backups need operational monitoring                     |
| Silent report mutation                          | Database triggers reject evidence/report/capture/revision updates and deletes                                 | Database administrator can alter schema; not a cryptographic audit log                 |
| Unbounded work                                  | One job at a time, at most four fixture pages, request/time/body limits                                       | No production disk quota or retention system                                           |
| Secret leaks                                    | Environment-only credentials, sanitized errors, API projections and checks                                    | Local environment/host logs and database are privileged resources                      |

No malicious public page is executed in this release. Do not expose the stack on a public interface or repurpose the fixture routing policy as a live crawler. Chromium runs under a non-root container user, but Playwright's browser launch and container networking are not a complete hostile-browser isolation boundary.
